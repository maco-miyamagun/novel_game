# 最初に

- 恋愛シミュレーションノベルゲーム『月が綺麗ですね』のレポジトリに足を運んでくださりありがとうございます。
- このレポジトリには、規約の関係上。シナリオスクリプト以外のゲーム内素材が含まれていません。また、一部の外部OSSも含まれていません。そのため、単独では動作しないことをご理解ください。
- また、MacOSマシンでの開発およびビルドのため。Windows向け環境ではCmakeLists.txtが正常に動作しません。ご了承ください。

# 作者maco-miyamagunの制作範囲について

- プロットとゲームシステム。UI・プログラム、キャラクター立ち絵は基本的に私が主体となって作成しています。
- しかし、並列処理や、指定秒待機、アセットの暗号化スクリプトなどは、github copilotのコード補完・コード生成を活用しています。
- また、プログラム内のコメント記述もコード生成を利用しています。
- また、背景画像とフォントに関しては、それぞれフリーで利用できる素材をお借りしました。

# レポジトリの探索方法ついて

- 「game_program」フォルダに、ノベルゲームのウィンドウ表示やシナリオスクリプトのパーサーなど、ノベルゲーム自体のロジックが記されたスクリプトがあります。
- 「script」フォルダに、ゲームのグラフィックの表示や並列処理機能、日本語フォントの読み込みなどの、基礎的なロジックが記されたスクリプトがあります。
- 「tools」フォルダには、ファイルの暗号化のための処理が記されたスクリプトがあります。（記載されている暗号化文字列は、サンプルでありビルド環境とは異なります。）
- 「resources」フォルダには、シナリオスクリプトのアセットが入っています。ここでノベルゲーム自体の具体的なイベントや分岐を制作しています。
